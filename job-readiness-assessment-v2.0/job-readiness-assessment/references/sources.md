# Sources

Load at workflow steps 1 and 3. Free sources only: no paid databases or services. Do not scrape sites whose terms forbid it; use postings supplied by the person.

## 1. Job and labour-market sources

| Source | Use |
|---|---|
| The posting (text or URL) | Primary input. Record URL and retrieval date; keep a copy, as postings are removed |
| Employer careers page | Confirm the posting; related roles |
| ESCO | Normalise skills, competences and occupations. Web-service and local API under EUPL 1.2; current version v1.2.1 [S1]; v1.2 has 3,039 occupations and 13,939 skill/knowledge concepts in 28 languages [S2]; each occupation maps to one ISCO-08 code [S3]; 96 transversal skills [S4] |
| France Travail API "Offres d'emploi" | Corroborate skill demand in France; licence required for developers [S7] |
| EURES | European vacancy portal and API [S7] |
| APEC barometers | French market context for managers and graduates [S8] |
| National public employment services and statistics offices | Equivalent sources for other countries |

## 2. Company sources (in order of preference)

1. Official website, product pages, press releases.
2. Official job posting and careers pages.
3. Annual reports, filings, investor materials.
4. Official company register of the employer's country (France: non-confidential annual accounts free via INPI [S9]); regulators; industry bodies.
5. Reputable press, with dates.
6. Other sources only if clearly marked low reliability.

Cite sources next to claims; date time-sensitive facts; disclose pages that could not be accessed.

## 3. Company profile elements

Cover where reliable information exists; state gaps.

| Group | Elements |
|---|---|
| Identity | Legal name, register ID, sector, headquarters |
| Size and structure | Workforce band, group or parent, ownership |
| Business model | How it earns revenue; main costs |
| Products and customers | Main offerings, segments, markets |
| Competitors | Direct competitors |
| Financial position | Revenue trend, profitability (if public) |
| Recent developments | Acquisitions, funding, restructuring, leadership changes, with dates |
| Strategic priorities | Only those stated publicly |
| Technology and tools | Visible in postings or technical publications |
| Working environment | Languages, international exposure, remote policy (if stated) |
| Culture and values | Stated values; external signals marked low reliability |
| ESG and regulation | Commitments, reporting obligations, sector rules |
| Role implications | Likely business questions for the role — tagged "Analysis" |

## 4. Provenance

For each external fact: source type, URL or file, publisher, publication date, retrieval date, licence (open data), claim supported.
